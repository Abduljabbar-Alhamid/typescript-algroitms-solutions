# typescript-algroitms-solutions

Solutions to DSA problems in TypeScript

## Overview

This repository contains solutions for several classical Data Structures and Algorithms problems implemented using TypeScript.

## Problems Included

1. Flood Fill
2. Trapping Rain Water
3. Climbing Stairs
4. Jump Game
5. Rod Cutting

---

## Technologies Used

- TypeScript
- Node.js

---

## Project Structure

```text
src/
 ├── problem1-flood-fill.ts
 ├── problem2-trapping-rain-water.ts
 ├── ...
```

---

## Installation

```bash
npm install
```

---

## Run Example

```bash
npx ts-node src/problem1-flood-fill.ts
```

---

## Algorithms Used

| Problem             | Technique           |
| ------------------- | ------------------- |
| Flood Fill          | DFS / BFS           |
| Trapping Rain Water | Two Pointers        |
| Climbing Stairs     | Dynamic Programming |
| Jump Game           | Greedy              |
| Rod Cutting         | Dynamic Programming |
